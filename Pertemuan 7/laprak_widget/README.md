# Tugas Praktikum Modul FLutter

## Penjelasan Widget

- **Container**: kotak berwarna untuk menampung & menata satu widget.
- **GridView**: menampilkan item dalam bentuk grid (3 kolom, 6 item).
- **ListView** : daftar vertikal sederhana (item A, B, C).
- **ListView.separated** : seperti builder, tapi ada Divider (garis) antar item.
- **Stack**: menumpuk beberapa widget; Positioned mengatur posisi.
